### ✅ O Que FAZER

1. **Leia toda documentação antes de começar**
   - Entenda a big picture
   - Valide decisões técnicas
   - Ajuste conforme sua realidade

2. **Use o roadmap como guia**
   - Siga semana-a-semana
   - Marque checkboxes conforme avança
   - Documente desvios

3. **Customize conforme necessário**
   - Esta é documentação, não código
   - Adapte para seu contexto
   - Mantenha docs atualizadas

4. **Implemente incrementalmente**
   - MVP primeiro (8 semanas)
   - Valide com usuários reais
   - Itere baseado em feedback

### ❌ O Que NÃO fazer

1. **Não tente implementar tudo de uma vez**
   - Siga o roadmap por fases
   - MVP primeiro

2. **Não mude stack sem motivo**
   - Decisões foram bem pensadas
   - Se mudar, documente o porquê

3. **Não pule testes**
   - Qualidade > velocidade
   - Dívida técnica cobra caro

4. **Não ignore observability**
   - Fundamental para debug
   - Implementar desde Phase 1
